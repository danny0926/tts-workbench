音訊準備說明

請為每種語言準備同一位說話者的 3 段乾淨參考錄音，每段 10–20 秒，合計約 30–60 秒。zh-TW 音訊放在 audio/reference/zh-TW/，日文放在 audio/reference/ja/。每段錄音需有完全一致的逐字稿，使用 UTF-8 編碼，且逐字稿內容必須是實際說出的原文。

檔名請讓 WAV 與逐字稿使用相同主檔名，例如：
audio/reference/zh-TW/speaker-zh-01-1.wav
audio/reference/zh-TW/speaker-zh-01-1.txt
audio/reference/ja/speaker-ja-01-1.wav
audio/reference/ja/speaker-ja-01-1.txt

建議使用單聲道 PCM WAV，16-bit 或 24-bit。優先保留原始取樣率；可用時建議 44.1 kHz 或 48 kHz，不要為符合建議而不必要地轉檔。錄音不要包含音樂、混響、音效或過度降噪、壓縮等激烈處理。

請在清單中為每段錄音標示語言（zh-TW 或 ja）及說話者 ID。若兩種語言確實由同一人錄製才使用相同 ID，否則請分開。日文參考錄音應使用日語母語者；非母語者的日文不得當作母語日文參考音訊。錄音者不必是使用者本人。

可依用途準備一般語氣與情緒語氣（例如開心或平靜）的片段，並在資料清單註明。可另外準備獨立的 held-out 評估錄音，每種語言約 30–60 秒，且內容必須與參考錄音不同。只提供你本人錄製或有權使用的錄音。原始與衍生音訊不會納入版本控制。

本階段不需要準備訓練語料；先完成免訓練的參考聲音複製比較，再判斷是否需要微調。
