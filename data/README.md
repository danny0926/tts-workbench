# 本機研究資料

公開儲存庫不提供真實研究 archive、逐字稿、人工備註、試聽回饋、來源索引或訓練清單。這些內容與含資料的舊歷史另存私人儲存庫，不會由 clone 自動取得。

自己的工作資料放在忽略追蹤的 `inputs/`、`outputs/`、`audio/`、`private/` 等目錄。先取得相符媒體、逐字稿與權利，再使用工具；缺檔不是已完成審核或可直接訓練。

`restore_archive.py` 保留給持有自己私人備份的人。只有自行放回忽略追蹤的 `data/archive/` 後才有可復原項目；預設預覽，不覆寫不同的現有檔案，也不還原媒體或權重。

不要將私人 repo 加為公開 repo 的 Git remote，亦不要將私人歷史 merge／push 到公開 repo。需要更新程式時只選擇性移植程式變更，並檢查 staged diff。
